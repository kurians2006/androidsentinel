# Contributing to AndroidSentinel

Thank you for your interest in making **AndroidSentinel** the standard open-source AI agent suite for Android, Kotlin, and Java developers!

---

## Areas You Can Contribute

1. **Rule Packages (`packages/rules/`)**:
   - Add new Kotlin Coroutines idioms, Jetpack Compose performance patterns, or Android 15/16 security rules.
2. **Skills (`packages/skills/`)**:
   - Enhance the review checklists for specialized libraries (e.g. CameraX, WorkManager, Room, Ktor).
3. **GitHub Action & CLI (`packages/github-action/`, `bin/`)**:
   - Improve PR inline comment diff matching and multi-provider LLM support.

---

## Submitting Pull Requests

1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/new-android-rule
   ```
2. Commit your changes:
   ```bash
   git commit -m "feat(rules): add WorkManager battery optimization rules"
   ```
3. Push to your branch and open a Pull Request.
